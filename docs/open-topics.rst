Open Topics
===========

The below are all topics yet to be covered in code club. If you want to suggest further topics, please make an `issue`_.

.. _`issue`: https://github.com/ResearchAxolotl/software-in-research/issues/new/choose

Topic: Contributing code to existing codebases
^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^^

Contributing to large existing projects or packages can be daunting.
Particularly so if they are open source, and any development is public for others to see.
This topic should guide researchers how they can get involved and collaborate.

*Learning outcomes:*

- How to go from problem identification, to Github issue creation, to engagement with the community and a solution, to pull request.
  What does this process look like?
- What is the difference between a fork of a repository vs. the upstream repository.
- Identifying and following project standards: README and licence files, any community contributing guidelines.

A code club on this topic may include:

- A showcase of a select issue and merged pull request from a well known package in the field.
  e.g. astropy, sunpy, plasmapy



Topic: Code Review
^^^^^^^^^^^^^^^^^^

Code review is an important process in your own code, when working collaboratively, and when using new code for the first time.
Reviewing code is a skill which will improve with practice.
However, it can be intimidating to jump into trying to understand a large chunk of code if you didn't write it yourself.

*Learning outcomes:*

- What should I look for when reviewing?
- What are common standards in code styling?
  Line lengths, whitespace, variable names, etc.
- How does code review help the person who wrote the code?
  How does it help the reviewer?

A code club on this topic may include:

- Asking members to bring some code they have written, and getting them to swap and review each other's work.
- A showcase of the reviews on a merged pull request from a well known package in the field.
  e.g. astropy, sunpy, plasmapy
