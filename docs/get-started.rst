Getting Started
===============

Thank you for thinking about contributing to code club.
We look forward to what you will present.
If you have any questions, please don't hesitate to get in touch.

Steps
-----

The steps are as follows:

1. Take a look at the `Open Topics`_ page.
   Choose something which you find interesting and want to learn about.

2. Spend some time researching the topic, make note of the suggested *learning outcomes*.

3. `Fork`_ and `clone`_ this respository (see the Github icon in the top right of this page).

4. Create a short tutorial page on that topic.
   See `our guide`_, and `other examples`_.
   Make a `pull request`_ to add it to this website.

5. Present that short tutorial during a code club session, explaining to others what you learned, and creating discussion with others more familiar with the topic.
